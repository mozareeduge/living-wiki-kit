# Wiki Handoff

Write `07-genesis/handoffs/YYYY-MM-DD--short-name.md`.

Required fields:

- branch and commit;
- task and intended result;
- exact files changed;
- exact files read;
- decisions accepted;
- decisions not made;
- validation commands and complete outcomes;
- unresolved findings;
- negative constraints;
- current corpus snapshot;
- next exact operation;
- rollback instruction.

Use compact factual prose. Do not replace evidence paths with a narrative summary.
