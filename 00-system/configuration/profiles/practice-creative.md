# Purpose

Artistic work where fragments, rehearsals, and unrealized possibilities are
first-class material.

# What this profile helps the system notice

Versions, abandoned routes, possibilities that never shipped, and how a work
changed across sessions.

# Anti-patterns

Do not force unfinished work into finished-work categories; absence of a
label is valid.
