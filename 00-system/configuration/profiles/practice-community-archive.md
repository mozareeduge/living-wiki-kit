# Purpose

Community and cultural archives where several perspectives about the same
object coexist without being flattened into one canonical narrative.

# What this profile helps the system notice

Who remembers what, where accounts diverge, and which interpretations are
live in the community.

# Anti-patterns

Do not resolve genuine disagreement into a single story; preserve the
multiplicity as data.
