# Purpose

Long-horizon inquiry with heterogeneous evidence and contestable claims.

# What this profile helps the system notice

Sources and their provenance, arguments and counter-arguments, methods,
open questions, and how positions changed over time.

# Useful labels

research-question, primary-source, secondary-source, methodological,
theoretical, case-study.

# Useful relations

supports, contradicts, extends, case-of.

# Anti-patterns

Do not let labels harden into a fixed ontology; keep questions open until
evidence closes them.
