# Rights and dependencies

The existing operator-supplied graph and reading interface is adapted for this kit at the operator's explicit request. This does not relicense the original artwork or its text, design or source archive. No artwork content or personal archive records ship with this plugin.

The archive adapter and supporting UI use the kit's existing record contracts. No canonical data is stored in this interface.

D3 7.9.0 is vendored from its npm package. Its original ISC copyright and permission notice is preserved in `vendor/D3-LICENSE.txt`. The plugin loads that local file and makes no CDN request. Obsidian is a separate proprietary application; its public plugin API is used without bundling the application.

Newsreader and Public Sans (SIL Open Font License 1.1) are embedded in main.js so the plugin makes no font request. Their licence texts are in `fonts/`.
