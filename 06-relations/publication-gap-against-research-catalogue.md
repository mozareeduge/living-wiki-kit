# The publication gap runs against the Research Catalogue genre

## Initial pressure

The research-campaign dossiers profile concrete external systems and standards and position the
operator's evidence-governed grammar against them. Relations below record how the profiled things
connect, at candidate tier, grounded only in the registered dossier text.

## Participants and profiles

- [[research-catalogue]]
- [[static-publication-layer]]
- [[exposition-format-export]]

## Current description

The RC exposition genre is built to publish process as scholarship; the operator's genesis machinery models process better than anyone but keeps it private, so from the field's viewpoint the process work is invisible. A static public layer (T1) or exposition-format export (T6) closes the gap without surrendering governance.
